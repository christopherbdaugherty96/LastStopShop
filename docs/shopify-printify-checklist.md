# Shopify + Printify Checklist

## Purpose

This checklist tracks what needs to be completed for LastStopShop as a Printify-powered Shopify POD shop hosted off Auralis Digital.

## Account / Store Setup

- [ ] Confirm Shopify store exists for LastStopShop.
- [ ] Confirm store name and sender email.
- [ ] Confirm support/contact email.
- [ ] Confirm payment provider.
- [ ] Confirm payout setup.
- [ ] Confirm legal business/profile settings.
- [ ] Confirm domain, subdomain, or hosted path from Auralis Digital.

## Printify Setup

- [ ] Connect Printify to Shopify.
- [ ] Confirm Printify store connection status.
- [ ] Choose preferred print providers.
- [ ] Confirm production regions.
- [ ] Confirm shipping regions.
- [ ] Confirm product cost and shipping cost before pricing.
- [ ] Confirm product mockup quality.

## Products

- [ ] Choose starter product types.
- [ ] Create first test product.
- [ ] Sync product to Shopify.
- [ ] Confirm variants sync correctly.
- [ ] Confirm product images appear correctly.
- [ ] Confirm title, description, tags, and SEO fields.
- [ ] Confirm pricing and profit margin.
- [ ] Confirm shipping profile.

- [ ] Catalog / all products

- [ ] Return/refund policy
- [ ] Privacy policy

- [ ] Order support page

## Customer Trust

- [ ] Add clear production time notice.
- [ ] Add clear shipping time notice.
- [ ] Add clear return/refund rules for POD products.
- [ ] Add contact/support method.
- [ ] Add fulfillment note explaining products are made after purchase.
- [ ] Add sizing charts where needed.
- [ ] Add mockup/product photo disclaimer if needed.

## Launch Checks

- [ ] Place a test order or run checkout test.
- [ ] Confirm mobile layout.
- [ ] Confirm cart works.
- [ ] Confirm checkout works.
- [ ] Confirm confirmation email works.
- [ ] Confirm Printify receives the order.
- [ ] Confirm product page buttons work.
- [ ] Confirm Auralis Digital links route correctly.
- [ ] Confirm policies are visible.
- [ ] Confirm support email works.
