# LastStopShop Build Plan

## Core Direction

LastStopShop is a print-on-demand shop using Printify connected to Shopify and hosted off the Auralis Digital umbrella.

The niche is not decided yet, so the first build phase should focus on structure, systems, policies, and launch readiness rather than final product direction.

## Build Phases

### Phase 1 — Foundation

- Define shop role under Auralis Digital.
- Document brand boundaries.
- Confirm Printify + Shopify workflow.
- Prepare required pages and policies.
- Prepare niche selection framework.
- Prepare starter collection structure.

### Phase 2 — Niche Selection

- Choose primary audience.
- Choose product style.
- Choose product categories.
- Choose design direction.
- Choose initial 10–20 product ideas.

### Phase 3 — Shopify / Printify Setup

- Connect Printify to Shopify.
- Create starter products.
- Sync product variants.
- Set pricing and margins.
- Configure shipping profiles.
- Confirm mockups.
- Add product descriptions and SEO fields.

### Phase 4 — Website Integration

- Add LastStopShop to Auralis Digital shop navigation.
- Create LastStopShop landing page or hosted section.
- Link to Shopify checkout/products.
- Make customer path clear.
- Add trust and policy sections.

### Phase 5 — Launch Readiness

- Run test checkout.
- Confirm fulfillment flow.
- Confirm return/refund language.
- Confirm support email.
- Confirm product images.
- Confirm mobile layout.
- Confirm all buttons and links.

## Initial Deliverables

- README direction
- Shopify/Printify setup checklist
- Niche decision framework
- Starter page list
- Launch checklist
- Product planning template
- Website integration notes
